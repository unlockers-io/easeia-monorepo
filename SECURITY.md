# Security policy

## Reporting a vulnerability

Email **hello@easeia.com** with the subject "Easeia security report". Include the
affected version or commit, steps to reproduce, expected impact, and a minimal
example using synthetic data. Do not include live credentials or customer data.

Please report vulnerabilities privately rather than opening a public issue.
We will investigate and coordinate disclosure with the reporter after a fix is
available. We do not currently offer a bug bounty or a guaranteed response time.

## Supported versions

Security fixes target the latest code on `main` and the latest published
`@easeia/astro-content` release. Older versions do not have a separate maintenance
commitment. Keep self-hosted instances and dependencies up to date.
