# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

SEO and affiliate operators managing their own private blog network and money sites.

## Product Purpose

Manage sites, draft posts, schedule Astro publishing, and inspect cross-site links and search performance from one dashboard.

## Capabilities and Constraints

Self-hosted, MIT licensed. Each instance has shared administrator access. Registration defaults to the first user only; hosted instances close signups. Optional OpenAI, DataForSEO, R2, Google Search Console, and Resend integrations must explain their configuration state. Full first-run flow: add site, configure deploy hook, create post, publish.

## Brand Commitments

Preserve the existing dashboard components, typography, tokens and layout. Use literal PBN and money-site terminology. Cloud is a waitlist with pricing undecided; do not invent paid plans, quotas, SSO or customer claims.

## Evidence on Hand

Repository implementation and synthetic demo data. Launch screenshots must use fictional .example sites.
